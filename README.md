# NovaStorms Navigator

NovaStorms Navigator is an interactive dashboard. It compares cities around the world for NovaStorms, a firm that sells analytics and AI that run on the customer's own servers. It asks where the firm could earn soonest, where it could learn and build next, when each step would pay, and how sure the answer is. Each result is shown with the evidence behind it and what could change it.

## Release

This page is the release at tag `ver2-2026-11-20`. It comes with the Data Report and the executive deck, built from the same numbers.

## Opens offline

The dashboard is one self-contained HTML file. Save it and open it in any modern web browser; it needs no internet connection and nothing to install.

## Where the numbers come from

Every number on the page is read by key from one numbers file, frozen at the release tag. Appendix A of the Data Report lists each key with its value and its source. The data are public, and every judgment call made after a result was seen is listed and marked.
